# Odin Recipes

A simple multi-page recipe website built as part of [The Odin Project](https://www.theodinproject.com/) foundations curriculum. The project practices core HTML skills: page structure, links between pages, images, and lists.

## Recipes

- [Amish Beef and Noodles](recipes/beef-and-noodles.html)
- [Hibachi-Style Fried Rice](recipes/fried-rice.html)
- [Lasagna](recipes/lasagna.html)

Each recipe page includes a title, photo, short description, ingredient list, numbered steps, and a link back to the home page.

## Built with

- HTML5 (headings, paragraphs, images, ordered and unordered lists, links)

## Project structure

```
.
├── index.html
├── README.md
├── images/
│   ├── beefandnoodles.jpeg
│   ├── friedrice.jpeg
│   └── lasagna.jpeg
└── recipes/
    ├── beef-and-noodles.html
    ├── fried-rice.html
    └── lasagna.html
```


## Running locally

No build step or dependencies are needed.

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click a recipe to view it, and use the "Home" link to come back.

## What I practiced

- Structuring pages with semantic HTML
- Using relative paths to link pages and load images across folders
- Writing ordered and unordered lists
- Adding descriptive `alt` text to images
